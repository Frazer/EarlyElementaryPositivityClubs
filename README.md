# ☀️ Early Elementary Positivity Clubs

A joyful, practical 60-minute club for young children combining:

- 🎵 sing-along music and movement
- 🧠 realistic, action-oriented affirmations
- 🧘 mindfulness games
- 💛 kindness and gratitude
- 🤝 friendship and belonging
- 🌱 growth mindset and emotional skills

The complete facilitator-friendly website is in **`index.html`**.

## Club motto

> **Notice the good. Create more good.**

## Run locally

No build step or dependencies are required. Open `index.html` directly in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

In the repository on GitHub:

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select **main** and **/(root)**
4. Save

GitHub will then publish the site from this repository.

## Philosophy

The club emphasizes optimism without denying reality. Affirmations are most useful when they are believable, flexible and connected to action: *“I can try again,” “I can ask for help,” “I can choose kindness.”*

Mindfulness is taught as playful attention training—not forced stillness. Children should always be free to pass on sharing, physical touch, eyes-closed exercises or any activity that feels uncomfortable.

## Music links

The site includes clickable YouTube search links for every suggested song so facilitators can choose an appropriate recording, lyric video, instrumental or licensed performance.
